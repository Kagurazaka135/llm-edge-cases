# Prompt 原文

两个实验用的 prompt 原文如下。所有调用 `temperature=0.7`，`max_tokens` 逐轮按需放宽。

---

## A · 原始题

用于全部 15 个模型的横评。**一句话，不点名主体、不给参考图。**

```
用 HTML 做一个"鹈鹕在海边的道路上骑自行车"的动画。
要求：
1. 输出一个完整、可直接保存为 .html 并双击打开就能跑的单文件（inline CSS + JS，不要引用任何外部资源/图片/CDN/字体）。
2. 必须真的动起来：鹈鹕骑车要有可见的动画循环（踩踏/车轮转动/背景滚动之类）。
3. 场景里要有海、公路、天空之类的海边元素。
4. 只输出 HTML 代码本身（放在一个 ```html 代码块里），不要额外解释。
```

变体：Opus 5.5 的 **run3** 在原文上追加了一句强调——
「**强调下是鹈鹕不是人**」（点名主体）。其余模型为原始题不加料。

---

## B · 开卷（详细文字规格）

把"答案写死"的一段描述，用于老模型与 Luna 的补课测试。
**关键：画面主体被逐条规定，禁止自由发挥。**

```
用 HTML 做一个动画，**画面主体严格按下面描述绘制，不要自由发挥、不要替换成别的主体**：

主角＝一只**鹈鹕骑着红色自行车**。鹈鹕的外形（必须画成鸟，不能画成人）：
- 身体：白色、圆润略胖的躯干
- 脖子：细长的白色脖颈向上伸
- 喙：橙黄色、很长很大的扁嘴，喙下方挂着一个**黄色的喉囊**（鹈鹕标志）
- 眼睛：小黑点；翅膀：白色带黑色翅尖

骑行姿态（关键）：鹈鹕的**身体坐在自行车座垫上方**，两只橙色的脚**踩在自行车脚踏上**，
一只翅膀**向前伸出去扶住车把**。不要画成"停在车顶"或"站在车旁"。

自行车：红色车架、两个带辐条的车轮、有车把和脚踏。

场景（海边公路）：
- 下方：灰色柏油公路，路中央有白色/黄色虚线
- 公路后面：一条土黄色沙滩
- 再往后：蓝色大海（画几条波浪线）
- 最上：蓝色天空，白色云朵，一个太阳
- 路边点缀几棵棕榈树、一座灯塔

动画：必须真的动起来——车轮持续转动、鹈鹕的腿做踩踏循环、背景（公路虚线/海浪）横向滚动。

技术要求：单文件 HTML（inline CSS + JS，不引用任何外部资源/图片/CDN/字体），双击可运行。
只输出 HTML 代码，放在一个 ```html 代码块里，不要任何解释。
```

---

## C · 隔离实验（V4.1-Flash）

分离"文字规格"与"视觉"两个变量。两次调用仅差"是否附带参考图"：

| 变体 | 内容 |
|------|------|
| `vision` | B 的详细文字规格 **+ 一张"鹈鹕骑车"参考截图**（多模态消息） |
| `textonly` | **仅 B 的详细文字规格，不给图** |

判定：两者**都画对了鹈鹕** ⇒ 起作用的变量是文字规格，不是图。
