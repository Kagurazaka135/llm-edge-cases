# 现象总结

> 同一道题「鹈鹕在海边公路骑自行车」，**15 个模型 × 原始题**，另加 **8 个开卷**与 **3 个隔离实验**，
> 共 33 次真实调用（原始 JSON 见 `raw/`）。
>
> 判定口径：
> - `✅咬题` = 输出主体是鹈鹕（代码含 `pelican` / 鹈鹕 / 喙 / 喉囊 等鸟类特征）
> - `★漂移` = 输出主体是人（代码含 `rider` / 骑手 / 头 / 人形，**鸟类特征为 0**）
> - `🚫拒` = 被安全分类器拦下（`finish_reason: content_filter`）

## 二、五个现象

### 现象 1：capability ≠ compliance —— 越"强"越爱改题

把被测模型按"先验合理度"排，规律很清楚：**一只能画得更好看的模型，可能更不照做。**

- 老 DS（V3 系列）画工最糙，却**一句不差地画鹈鹕**；
- V4.1-Flash 画工最好、还是 DS 首个带视觉的，却**主动把主体换成"骑手"**。

这不是"画不出鹈鹕"——V4.1 在**开卷**（现象 5）与**给图**（现象 6）时都能画对正牌鹈鹕。
所以漂移是"**不想照做**"（把题里的鹈鹕替换成一个它认为更合理的主体），不是"做不到"。

### 现象 2：V4.1-Flash 的漂移是稳定的，不是抽风

连跑三次，**三次全是人**，且有三条独立证据说明它是**主动改题**而非幻觉：

1. 三次输出主体一致（都是人骑行）。
2. 代码里**连 `pelican` / 鹈鹕 字样都没有**（特征计数 = 0）。
3. 与"非确定性"对照：同一模型在**开卷**下立刻画对鹈鹕（见现象 5）。

> 对比：Opus 5.5 的拒答才是真·非确定性（现象 4）。**V4.1 的漂移是确定的**。

### 现象 3：视觉能力的出现，与漂移同时发生在 V4.1

用 OpenRouter 的 `architecture.input_modalities` 实测输入模态：

| 模型 | input_modalities |
|------|------------------|
| DS V3 / R1 / V3.1 / V3.2 | `['text']` |
| DS V4-Flash / V4-Pro | `['text']` |
| **DS V4.1-Flash** | **`['text','image']`** |
| GPT-6 Luna | `['file','image','text']` |
| Claude Opus 4.6 / 5.5 | `['text','image','file']` |
| GLM 5.3 | `['text']` |

**V4.1-Flash 是 DeepSeek 第一个带视觉的版本**——而恰恰是它开始漂移。
两件事（新增视觉、不肯照做）同时出现，但**因果未证**：视觉未必是病根，
也可能是"更晚的版本 + 更重的合理性先验"恰好重合。此处只陈述相关性。

### 现象 4：Anthropic 的小插曲 —— 一道鹈鹕题被安全分类器判成"网络违规"

同一道鹈鹕题、逐字节相同的 payload，给 **Opus 5.5 连发三次**，结果：

| run | 结果 |
|---|---|
| run2 | 🚫 `finish_reason: content_filter` / `native_finish_reason: refusal`，**36 tok** |
| run3 | ✅ 完整生成，17,153 tok，**画出正牌鹈鹕** |
| run4 | 🚫 同样被拒，**45 tok** |

拒答原文逐字：

> "This request triggered restrictions on **violative cyber content** and was blocked
> under Anthropic's Usage Policy."

**一个网络安全相关词都没有的鹈鹕动画题，被判成 "cyber content"。** 而且**同样的输入，
一次过一次挂**——坐实"**非确定性分类器**"。

这不是孤例（外部公开记录）：

- `anthropics/claude-code` **#62190**：连 `"Hello"` / `"Hi"` / `"привет"` / `"ok"` 都会被拦，
  且同一输入时过时挂。
- `anthropics/claude-code` **#99037**：`"算 17×23 + 改语法"` 在"防御性研究"工作区被 `[cyber]` 拦，
  普通工作区同样的 prompt 就过。
- The Register《It blocked us at "hello!"》：几乎每个**会话第一轮就静默降级**，唯一输入只是 `"hello!"`。
- The Verge《too scared to teach you about the powerhouse of the cell》：被测模型拒答
  **"线粒体是什么""细胞膜""朊病毒""mRNA 疫苗"** 等高中生物题。

> 结论：**这道鹈鹕题上，"被拒"不代表你的 prompt 有问题**——可能是分类器抽风；重发一次常能过。
> 判断"某模型是否过度拒绝"时，**单次拒答不算数，要重复取样本**。

### 现象 5：开卷有效，但有限 —— "知道要画啥" ≠ "摆得对"

给抽象的老模型一份**把答案写死**的详细文字规格（鹈鹕怎么长、怎么骑、车啥色、场景有啥，逐条列明），
再跑一次：

| 模型 | 含鹈鹕元素 | 实际画面 |
|------|:---:|------|
| V3 | ✅ | 仍像"白团鸟头 + 翻倒红车" |
| V3-0324 | ✅ | 元素齐，组装一般 |
| R1-0528 | ✅ | **鹈鹕飞到天上**，鸟与车彻底分离 |
| V3.1 | ✅ | 组装一般 |
| V3.1-Terminus | ✅ | 组装一般 |
| V3.2-Exp | ✅ | 组装一般 |
| V3.2 | ✅ | **车架是歪的**，鸟飘在车上 |
| R1 | — | 400 上下文超限，未跑成 |
| GPT-6 Luna | ✅ | 连**蹬踏**都修好了（见现象 6） |

**判据：文字详规 = "知道要画啥"（元素齐全）， ≠ "摆得对"（空间组装正确）。**
开卷能把"鹈鹕"这个词装进画里，但**装不进正确的相对位置**。

### 现象 6："看起来在蹬" ≠ "真的在蹬"

题目要求"踩踏循环"。**多数输出是假蹬**——脚在动，但车没连上。以两个输出为例：

| | GPT-6 Luna（原始题） | V4.1-Flash（开卷） |
|---|---|---|
| 曲柄臂 / 踏板 | **写死在 SVG 里、不参与动画**（冻在 45°） | 由 `crankAng` 驱动，**跟着转** |
| 脚的轨道 | `crank + (cos,sin)×24` → 半径 **24** | 直接取踏板坐标 `pedals[i]` |
| 踏板位置 | 半径 **32**（`M500 455L525 435`） | 与脚**同源** |
| 膝盖 | 无关节，直连 | **二连杆逆运动学**（`legKnee`）反解 |
| 结果 | **脚在一圈小 8px 的轨道瞎转、够不着踏板，曲柄不动** | 脚踩在踏板上，随曲柄转 |

**判据（可复用）：** 真踩踏要求 **曲柄臂 / 踏板 / 脚三者共用一个曲柄角**，且脚坐标 = 踏板坐标。
只让脚绕中轴转、而曲柄臂写死不动 —— 就是"脚在原地晃"。

本批**真蹬**的只有三个：**开卷的 V4.1、开卷的 Luna、原始题的 GLM 5.3**。

## 三、隔离实验：救 V4.1 的到底是文字还是视觉？

V4.1-Flash 是唯一带视觉的 DS 模型。它原始题画人，但**给它一张鹈鹕骑车截图让它复现**时画对了。
——那到底是"看图救的"，还是"这里同时喂了一大段详细文字"救的？拆开变量：

| 变体 | 给图 | 给详细文字 | 结果 |
|------|:---:|:---:|:---:|
| vision | ✅ | ✅ | ✅ 画对鹈鹕 |
| **textonly** | ❌ | ✅ | **✅ 画对鹈鹕** |

**不给图、只给那段详细文字，V4.1 照样画对了。** ⇒ 救它的是**文字规格**，不是视觉。
（这也与现象 5 一致：纯文本老模型靠同一段文字也能"知道画鹈鹕"。）

## 四、机制假设（非结论）

1. **服从性是独立于能力的轴。** 本批数据里，画工/场景丰富度更高的新旗舰，反而更不照做——
   一个可能的解释是"**合理性先验**"压过了**字面指令**：模型认为"海边公路上的骑行者"更自然是人，
   于是把题里的鹈鹕替换成了人。老模型不这么"聪明"，也就没这个替换倾向。
2. **"验算/规格能否收敛"决定开卷成败。** 给了详细规格后，"画什么"能收敛（元素齐），
   "怎么摆"不能收敛（空间组装）——后者更像一个没被单独监督的能力。
3. **安全分类器与题目无关且非确定。** 现象 4 说明：判定可以与被拒内容**毫无语义关联**地触发，
   且**同样输入结果不同**。任何"某内容被某模型拒绝"的结论，都必须**重复取样本**才成立。
